# Motorola Mobile Sales Analysis | Power BI

Power BI dashboard for analyzing Motorola mobile sales performance, customer behavior, and transaction trends.

## Key Features

- Total Sales, Quantity, Transactions & Average Sales
- Monthly Sales Trend
- Sales by Mobile Model
- Payment Method Analysis
- Customer Rating Analysis
- Day-wise Sales Analysis
- Geographical Sales Analysis
- Interactive Filters

## Tools Used

- Power BI
- DAX
- Power Query
- Data Modeling
- Data Visualization

## Project File

The Power BI dashboard is included in this repository as a `.pbix` file.
